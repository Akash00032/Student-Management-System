🎓 Student Management System (Java Swing + JDBC + MySQL)
The Student Management System is a desktop-based CRUD application developed in Java using Swing for the GUI, JDBC for database connectivity, and MySQL as the backend database. This system allows administrators to add, update, delete, and search student records, making it ideal for managing student data in small institutions or as a Java learning project.

🛠️ Features

📋 Add New Student

✏️ Update Student Information

🗑️ Delete Student Record

🔍 Search Students by Name or Department

📊 View All Students in a JTable with a styled UI
